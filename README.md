# engineer-agents-md

Personal global engineering rules (`AGENTS.md`) synthesized across real multi-agent projects to keep coding agents disciplined, maintainable, and free of AI slop.

## Install Globally

### Antigravity (`agy`)
```bash
cp AGENTS.md ~/.gemini/config/AGENTS.md
```
*(If using T3 Code's isolated `GEMINI_HOME`, symlink `~/.t3/userdata/providers/antigravity/<hash>/config/AGENTS.md` to `~/.gemini/config/AGENTS.md`.)*

### Codex (`codex`)
```bash
cp AGENTS.md ~/.codex/AGENTS.md
```

Project-level `AGENTS.md` files automatically take precedence when repo conventions differ.
